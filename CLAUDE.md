# Baseline — project notes for Claude sessions

Read [`AGENTS.md`](AGENTS.md) at the repo root first: the working rules live there and
apply to every session — **the landing protocol (its first section: "land it" means
commit *and* push to `main`, no step-by-step confirmations)**, the roadmap-note commit
ceremony (every non-merge commit), checkout-root discipline, the i5 deploy lane, and
any dated **TEMP RULE** sections currently in force.

If you are a one-off worker session: you are expected to finish on `main`. Read the
landing protocol before asking the operator a procedural question — the answer to
"should I commit / push / merge this?" is already there, and asking costs them a full
context charge for a question the repo has answered.

Cold pickup: [`HANDOFF-2026-07-29.md`](HANDOFF-2026-07-29.md) (state, pending-by-actor,
resume recipes). Product boundary before packaging or outward copy:
[`docs/baseline-vision-and-boundary.md`](docs/baseline-vision-and-boundary.md).

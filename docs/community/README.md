# For players and community members

Tools you can download and run on your own machine. No server, no account, no signup.

**The catalog lives here → [the Community Workbench](https://am4.tail8e749c.ts.net/workbench)**

Every card on that page says what the thing actually does *today* — not what it's
planned to do. If something is half-built, the card says so.

## Three things you can run tonight

### Quest Picker
Turns a guild's real quest tracker into a single offline page where a player checks the
quests they care about — and the game mod reads the result. Runs as a local HTML file;
nothing is uploaded anywhere.

### ComfyStewardView
Point it at a Valheim world save and get a map: build density, portals, players, who
owns what. It answers the questions that stop being walkable once a server gets big.

### Community Telemetry
An aggregates-only telemetry API — with privacy tests that *fail* if a player ID, name,
or position ever appears in a response. Not promised, tested. The whole stack runs on
your machine.

## What's in the catalog but not runnable yet

**Steam Self-Service Join** — an invite, a Steam sign-in, and a mod-pack zip with your
credentials already in it. This is built and it works on the gateway, but it is **not
publicly reachable right now**, and the game server it would connect you to is not open.
Don't plan an evening around it yet.

**Two recoverable pieces** — a camera that flies a world save's best builds into a
gallery, and a bridge that turns a quest submission into something a GM can review.
Both proved themselves before being cut for time. Reviving either is a real claim on it,
not a warm-up exercise.

## What to expect

Read **[what alpha means here](expectations.md)** before you file your first bug. Short
version: one operator, best-effort, built in the open, and honest about the boundaries.

## Where to talk about it

**[Join the Discord](https://discord.gg/JCDaYQ68kN)** — each tool has its own thread in
the `#workbench` forum.

Post what you tried in the tool's thread rather than in DMs, so the next person who hits
the same thing finds your answer. Running one of these once and saying what happened —
**including that it broke** — is a complete contribution.

## Taking one over

There's a ladder, and the first rung costs you one evening:

| Stage | What you did |
|---|---|
| **Curious** | Read a tool's one-pager and decided whether it's worth your evening. |
| **Ran it** | Ran it locally and posted what happened, including the part where it broke. |
| **Fixed one thing** | Completed one of the first tasks listed on a tool card. |
| **Contributor** | Landed two changes, or revived a recoverable piece into something that runs. |
| **Owner** | Sustained it over time, and you're the person holding it. |

Volunteers already carried this community. An unclaimed tool is not a verdict on anyone.

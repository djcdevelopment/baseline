Valheim custom fields

A community guide built on one idea: a custom field belongs to a component, not a prefab. Learn a component's fields once and you can apply them to every prefab that carries it.
Every field name, type, and count in this guide is extracted from assembly_valheim.dll — regenerated after game patches, never re-researched.
The guide is layered: Level 1 teaches the prefab→component→field concept with no C# at all, Level 2 gives per-component field dictionaries, and Level 3 opens the machinery — synced ZDO state, instance RPCs, the ownership contract, and where Harmony hooks land.
